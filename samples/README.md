# サンプルファイル

アップロードの動作確認と、テストに使うファイルです。

**`サンプル株式会社` は架空の会社で、ここにある規程は、実在の会社のものではありません。**

| ファイル | 内容 | 用途 |
|---|---|---|
| `dummy_policy.pdf` | ダミーの就業規則（3ページ、全13条）。1ページ目: 第1〜4条、2ページ目: 第5〜8条、3ページ目: 第9〜13条 | 通常のアップロード |
| `dummy_policy_revised.pdf` | 改定版（年次有給休暇を、10日から12日に変更） | 規程の置き換えの確認（置き換えると、チャットの回答が12日に変わる） |
| `users.csv` | ユーザーの一括登録用のCSV（架空のメールアドレス3件） | `import_users` の動作確認 |
| `invalid/no_text.pdf` | 画像だけのPDF（文字がなく、テキストを抽出できない） | アップロードのエラーの確認 |
| `invalid/not_a_pdf.pdf` | PDFではないファイル（拡張子だけが `.pdf`） | アップロードのエラーの確認 |

## 補足
- PDFは、テキストを元に、ブラウザの印刷機能（ヘッドレスのChrome）で作成しました。
- このPDFから抽出したテキストには、見た目は同じでも、別の文字コードの文字（部首用の文字。例: 「目」が「⽬」、「民」が「⺠」）が混ざります。PDFの作り方によって起こる、よくある現象で、アップロード時に、通常の文字に直します。
